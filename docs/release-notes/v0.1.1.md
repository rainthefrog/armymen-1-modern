## Army Men Modern v0.1.1 (Alpha)

> **Early Alpha Build:** This release focuses on stability, portable single-file installation, tester diagnostics, and startup behavior.

A drop-in modernization mod (`ddraw.dll`) for the original **Army Men (1998)** PC game. It preserves the campaign, missions, and original visual identity while adding modern display support, controls, tactical information, and gameplay improvements.

**Bring your own game.** This download contains no Army Men assets, executables, HD packs, or Army Men II audio files. It patches the unmodified GOG release of `Armymen.exe` in memory and uses the original artwork by default.

### New in v0.1.1

- **Mission-win crash fixed:** the experimental save-state flag now ships disabled, so normal play keeps the game's original memory manager. Its code remains in place for continued development, but enabling it is unsupported until its mission-win crash is fixed.
- **Startup clicking restored:** any click or key once again skips the intro video and the post-video legal screen in the portable, original-art build.
- **Single-file portable release:** install only `ddraw.dll`; no INI, manifest, installer, or HD-art folder is required.
- **Cleaner Mod Settings:** related options are grouped into five pages, with separate Classic gameplay and Modern HUD layout presets.
- **Tester logging:** diagnostic logging is available in Mod Settings and retains the previous run as `armymen-mod.prev.log`.
- **Session recording improvements:** recordings now preserve explicit mission transitions, semantic menu clicks, stop waypoints, mod-action tags, and mission boundaries for reproducible tester reports.
- **Original-art defaults:** optional HD world, sprite, menu, and video art remain off in the portable release.

### What's in the mod

- True widescreen and ultrawide battlefield rendering, resizable windows, borderless fullscreen, Direct3D 11 presentation, DPI awareness, and correct high-refresh pacing.
- Modern mouse/WASD controls, point-and-click pathfinding, sprinting, mouse aiming, stance controls, throw previews, configurable bindings, and gamepad support.
- Scalable sliced HUD groups, enhanced minimap, hover details, pinned objectives, target sectors, mission routes, enemy awareness, health bars, and command radial.
- Six weapon positions, stacked ammunition, enemy weapon drops, carried medkits, improved mines/minesweeper behavior, squad upgrades, and weapon carry-over between scenario parts.
- Vehicle pathfinding, reversing and turning, independent turret aim, overlap recovery, enemy vehicle capture, and optional vehicle bail-out.
- Classic gameplay preset, separately optional centered classic HUD, CRT filter, optional Army Men II audio packs, built-in updater, and extensive crash/correctness fixes.

### Install on Windows (GOG)

1. Download `ddraw.dll` from this release.
2. Copy it beside `Armymen.exe` in the Army Men installation folder.
3. Launch the game normally.

The original executable is never modified. Settings and tester logs are written beside the DLL.

### Install on Linux / Steam Deck / Bazzite

1. Place `ddraw.dll` beside `Armymen.exe`.
2. Add this Steam launch option (or the equivalent Wine environment setting):

   ```text
   WINEDLLOVERRIDES="ddraw=n,b" %command%
   ```

3. Launch the game normally.

### Updating and uninstalling

- **Automatic update:** the mod can check GitHub Releases, verify `ddraw.dll.sha256`, replace the DLL, and restart the game.
- **Manual update:** replace the existing `ddraw.dll`. Campaign saves and mod settings remain intact.
- **Uninstall:** delete `ddraw.dll` and optionally `armymen-mod.ini`, `armymen-mod.log`, `armymen-mod.prev.log`, and `recordings\`.

Existing `SaveGames\quick*.ams` files from v0.1.0 are no longer loaded and may be deleted. The game's normal campaign saves are unaffected.

### Useful shortcuts

- **`F10`** — Open Mod Settings (`Shift+F10` opens the compact overlay and binding editor)
- **`F11` / `Alt+Enter`** — Toggle borderless fullscreen
- **`F9`** — Toggle the CRT filter
- **`Ctrl+Wheel` / `Ctrl+PgUp` / `Ctrl+PgDn`** — Battlefield zoom
- **`Pause` / `Ctrl+-` / `Ctrl+=` / `Ctrl+0`** — Pause or adjust game speed

### Tester reports and diagnostics

Enable **Logging** in Mod Settings, reproduce the issue, and attach `armymen-mod.log`; the previous run is retained as `armymen-mod.prev.log`.

Session recording is enabled by default and writes JSONL traces to `recordings\`; `Ctrl+Shift+B` adds a checkpoint bookmark. Set `[debug] record_runs=0` in `armymen-mod.ini` to disable it.

### Compatibility notes

- Built for the **GOG Windows release** of Army Men (1998).
- The release contains no optional HD art or Army Men II audio assets.
- Wine verification covered startup/menu navigation, the Desert 1 mission-win transition, the original-art portable profile, and absence of exceptions. Windows startup clicking was confirmed by the user.
